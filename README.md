# QQ 邮箱查收作业班长小助手

一个面向班级作业收集场景的 Windows 本机工具。按需连接 QQ 邮箱，依据作业固定标识、日期范围和学号统计 PDF 提交情况；支持追溯附件来源、导出到桌面、整理未交名单，并在人工检查后批量发送提醒。

> 本项目只在你点击扫描时读取 QQ 邮箱收件箱，不进行实时或后台监控。邮件、花名册、统计数据库和作业附件保存在运行本机，不会由本工具上传到云端。

## 功能

- 使用 QQ 邮箱 IMAP 按需扫描收件箱，按接收日期、固定作业标识及关键词筛选 PDF。
- 维护 QQ 号、学号、班级/小组及已核实邮箱；支持 CSV 导入和导出。
- 从 `.docx` Word 文档或可搜索文字的 PDF 识别姓名、学号、QQ 号与班级/小组；确认前可预览、修正字段并设置默认分类。
- 使用登记邮箱、QQ 号或所选邮件字段中的唯一学号识别提交人。多个学号或身份信息冲突时标记待确认，不自动归属。
- 按名单统计已交、未交和迟交，并记录邮件主题、发件地址、接收时间和 Message-ID。
- 下载所选附件，按 SHA-256 校验，并为文件保留来源清单。
- 一键将本次任务的 PDF 和来源清单导出到桌面新建的自动命名文件夹。
- 为未提交且邮箱已核实的成员生成提醒草稿；检查名单和内容后，可批量发送。
- 在“提交名单”按分类筛选成员，编辑统一主题和正文后逐人发送批量通知；只发送到已登记且核实过的邮箱，并在本机查看发送结果。
- 本机 SQLite 保存花名册和历史统计；服务仅监听 `127.0.0.1`。

## 运行环境

- Windows 10 或更新版本
- Python 3.9 或更新版本
- PDF 花名册识别依赖 `pypdf`（通过 `requirements.txt` 安装）
- QQ 邮箱已开启 IMAP/SMTP，并已生成客户端授权码

## 启动

下载或克隆项目后，在项目文件夹运行：

```powershell
python -m pip install -r requirements.txt
pythonw app.pyw
```

程序启动后会打开本机网页。如果没有配置 `pythonw` 命令，可以运行 `python app.pyw`。默认访问地址为 `http://127.0.0.1:8765`；如果端口被占用，程序会在后续端口中查找可用地址。关闭本机服务进程即可退出。

## 首次设置

1. 在 QQ 邮箱设置中启用 IMAP/SMTP 服务并生成客户端授权码。授权码只保存在运行中的进程内存，关闭程序后需重新连接。
2. 在网页右上角连接邮箱，输入 QQ 邮箱地址和客户端授权码。
3. 在“提交名单”登记成员，导入 CSV，或选择 Word / PDF 名单。Word/PDF 表格需有“姓名、学号、QQ号”表头；分类列可使用“班级、小组、分类”。检查预览并确认后才会写入。未提供分类列时可填写默认分类；已登记成员的邮箱信息会保留。
4. 在统计任务中填写作业名称、日期范围和固定作业标识，例如“第二次数据结构作业”，再选择主题、正文或附件文件名作为检索位置并启动扫描。
5. 检查提交状态及未匹配发件人。身份有冲突或不明确的邮件不会自动计为某位同学已提交。

## 提醒规则

提醒列表只包含尚未提交、邮箱已登记并勾选为“已核实”、且该任务此前未提醒过的成员。发送前可以检查邮件内容并取消选择个别成员；点击“一键发送催促”后，所选邮件将通过已连接的 QQ 邮箱发送。每位成员每个任务只会被自动提醒一次。

## 批量通知

在“提交名单”点击“批量通知”，选择成员分类并勾选收件人，填写统一邮件主题和正文。系统会逐人发送独立邮件，不会让收件人看到其他成员邮箱。只有邮箱已登记、已核实且成员仍在册时才可发送；一次最多 200 人。每次群发内容、收件人及成功/失败状态会保存在本机“最近通知”记录中。此功能通过 SMTP 发送邮件，不会仅凭 QQ 号推断邮箱地址。

## 本地数据与隐私

- `data/assistant.sqlite3`：花名册、任务筛选条件、邮件来源索引、提醒记录和批量通知发送记录。
- `downloads/`：下载的 PDF 及对应 `.source.json` 来源清单。
- 桌面导出目录：用户点击导出后创建，包含匹配的 PDF 和来源清单。
- 不要将授权码、花名册、作业附件、数据库或带会话参数的邮箱链接提交到 GitHub。
- 作业文件可能包含姓名、学号等个人信息，请按学校要求控制本地访问和保留期限。

## 已知范围

- 当前仅扫描 QQ 邮箱 `INBOX`，不遍历其他文件夹或邮箱，不做定时监控。
- 当前仅下载 PDF 附件，不自动打开或解析附件内容。
- 名单文件仅支持 `.docx` 和可选择文字的 PDF；旧版 `.doc` 请另存为 `.docx`。扫描图片版 PDF 暂不支持 OCR。单文件上限 8 MB、PDF 最多 100 页、每次最多 1000 条记录。
- 学号必须事先登记且唯一；只有所选检索位置出现完整学号时才用于身份匹配。
- 邮箱发送依赖 QQ 邮箱 SMTP 设置和有效的客户端授权码。
