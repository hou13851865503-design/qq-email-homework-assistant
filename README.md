# QQ 邮箱查收作业班长小助手

一个面向班级作业收集场景的 Windows 本机工具。按需连接 QQ 邮箱，依据作业固定标识、日期范围和学号统计作业提交情况；支持追溯附件来源、导出到桌面、整理未交名单，并在人工检查后批量发送提醒。

> 本项目只在你点击扫描时读取 QQ 邮箱收件箱，不进行实时或后台监控。邮件、花名册、统计数据库和作业附件保存在运行本机，不会由本工具上传到云端。

## 功能

- 使用 QQ 邮箱 IMAP 按需扫描收件箱，按接收日期、固定作业标识及关键词筛选 PDF。
- 维护 QQ 号、学号、班级/小组及已核实邮箱；支持 CSV 导入和导出。
- 从 `.docx` / `.xlsx` 表格、老版 `.doc` / `.xls`（借本机 Office 转换）或可搜索文字的 PDF 识别姓名、学号、QQ 号与班级/小组；确认前可预览、修正字段并设置默认分类。
- 使用登记邮箱、QQ 号或所选邮件字段中的唯一学号识别提交人。多个学号或身份信息冲突时标记待确认，不自动归属。
- 按名单统计已交、未交和迟交，并记录邮件主题、发件地址、接收时间和 Message-ID。
- 下载所选附件（不限制文件类型，按发件人姓名与文件名匹配），按 SHA-256 校验，并为文件保留来源清单。
- 一键将本次任务的文件导出到桌面新建的自动命名文件夹（导出后自动打开该文件夹）；来源清单收在同级 `来源清单/` 子目录里，不和学生提交的文件混在一起。
- 为未提交且邮箱已核实的成员生成提醒草稿；检查名单和内容后，可批量发送。
- 在“提交名单”按分类筛选成员，编辑统一主题和正文后逐人发送批量通知；只发送到已登记且核实过的邮箱，并在本机查看发送结果。
- 本机 SQLite 保存花名册和历史统计；服务仅监听 `127.0.0.1`。

## 运行环境

- Windows 10 或更新版本
- Python 3.9 或更新版本
- PDF 花名册识别依赖 `pypdf`（通过 `requirements.txt` 安装）
- QQ 邮箱已开启 IMAP/SMTP，并已生成客户端授权码

## 启动

下载或克隆项目后，在项目文件夹运行：

```powershell
python -m pip install -r requirements.txt
pythonw app.pyw
```

程序启动后会打开本机网页。如果没有配置 `pythonw` 命令，可以运行 `python app.pyw`。默认访问地址为 `http://127.0.0.1:8765`；如果端口被占用，程序会在后续端口中查找可用地址。关闭本机服务进程即可退出。

## 从本地工作台启动

如果本机装了工作台门户（`http://127.0.0.1:8770`），点卡片「QQ 邮箱作业班长助手」会由门户调用 `GET /api/launch?app=homework` 拉起本程序：它在后台用 `pythonw app.pyw` 启动，等 `8765` 端口就绪后再把页面切过去。**已经在跑就直接复用，不会重复启动。**

这种情况下不用记端口，工作台会处理；单独使用时仍按上一节的地址访问。

## 首次设置

1. 在 QQ 邮箱设置中启用 IMAP/SMTP 服务并生成客户端授权码。勾选「记住此设备」后，授权码会加密保存在本机，下次启动自动连接，无需重复生成。
2. 在网页右上角连接邮箱，输入 QQ 邮箱地址和客户端授权码。首次连接后程序会自动重连，界面顶部会短暂显示「连接中…」。
3. 在“提交名单”登记成员，导入 CSV，或选择 Word / Excel / PDF 名单。三种表格都需有“姓名、学号、QQ号”表头；分类列可使用“班级、小组、分类”。检查预览并确认后才会写入。未提供分类列时可填写默认分类；已登记成员的邮箱信息会保留。
4. 在统计任务中填写作业名称、日期范围和固定作业标识，例如“第二次数据结构作业”，再选择主题、正文或附件文件名作为检索位置并启动扫描。
5. 检查提交状态及未匹配发件人。身份有冲突或不明确的邮件不会自动计为某位同学已提交。

> **固定作业标识是硬条件，不是备注。** 填进去的字符串必须**真实出现**在所选检索位置（主题 / 正文 / 附件文件名之一），否则即使关键词命中，该邮件也会被排除。填错了不会报错，只会看到「匹配文件 0」——因此扫描后若一个文件都没有，而诊断提示说有几封命中了关键词，多半就是这一项挡住的，清空后重扫即可。

## 提醒规则

提醒列表只包含尚未提交、邮箱已登记并勾选为“已核实”、且该任务此前未提醒过的成员。发送前可以检查邮件内容并取消选择个别成员；点击“一键发送催促”后，所选邮件将通过已连接的 QQ 邮箱发送。每位成员每个任务只会被自动提醒一次。

## 批量通知

在“提交名单”点击“批量通知”，选择成员分类并勾选收件人，填写统一邮件主题和正文。系统会逐人发送独立邮件，不会让收件人看到其他成员邮箱。只有邮箱已登记、已核实且成员仍在册时才可发送；一次最多 200 人。每次群发内容、收件人及成功/失败状态会保存在本机“最近通知”记录中。此功能通过 SMTP 发送邮件，不会仅凭 QQ 号推断邮箱地址。

## 授权码如何保存

勾选「记住此设备」后，账号与授权码会保存为 `data/session.bin`，下次启动自动连接，不必重新生成授权码。

| 环节 | 做法 |
| --- | --- |
| 存储位置 | `data/session.bin`（`data/` 已在 `.gitignore` 中，不会进仓库） |
| 加密方式 | Windows DPAPI（`CryptProtectData`，当前用户作用域）。密钥由 Windows 账户托管，文件复制到别的电脑或别的 Windows 账户都解不开 |
| 加载时机 | 程序启动时、起 HTTP 服务之前同步解密一次（只解密不联网，毫秒级），因此页面一打开就是「已记住 xxx」；随后后台线程用凭据登录，界面在这段时间显示「连接中…」，成功后自动切换为已连接 |
| 清除方式 | 界面点「断开并忘记」会删除该文件；也可手动删除 `data/session.bin` |

授权码异常时的处理：

- **本机没有保存过**：界面显示「连接邮箱」，手动填写即可。
- **授权码被 QQ 邮箱拒绝**（已作废、或在别处重新生成过）：提示重新生成授权码，同时**保留**本机文件——只要之后填回同一个授权码就不必再改。
- **网络不通或超时**：提示检查网络，不会误报成授权码失效，避免用户白白重新生成而作废原本有效的授权码。
- **文件解不开**（换了 Windows 账户、文件损坏）：界面提示具体原因，并写一行到 `data/app.log`，方便排查；不会静默退化成「又忘了」。

## 本地数据与隐私

- `data/assistant.sqlite3`：花名册、任务筛选条件、邮件来源索引、提醒记录和批量通知发送记录。
- `downloads/`：下载的 PDF 及对应 `.source.json` 来源清单。
- 桌面导出目录：用户点击导出后创建，根目录只放匹配到的附件；`.source.json` 来源清单放在 `来源清单/` 子目录，需要核对来源时再进去看。
- 不要将授权码、花名册、作业附件、数据库或带会话参数的邮箱链接提交到 GitHub。
- 作业文件可能包含姓名、学号等个人信息，请按学校要求控制本地访问和保留期限。

## 已知范围

- 当前仅扫描 QQ 邮箱 `INBOX`，不遍历其他文件夹或邮箱，不做定时监控。
- 当前仅下载所选附件，不自动打开或解析附件内容；PDF 扫描件需要 OCR 的场景仍不支持。
- 名单文件支持 `.docx`、`.xlsx` / `.xlsm`（纯 Python 解析，无需额外依赖）、老版 `.doc` / `.xls`（借本机 Office 转换，未安装会提示另存为新格式）和可选择文字的 PDF；扫描图片版 PDF 暂不支持 OCR。单文件上限 8 MB、PDF 最多 100 页、每次最多 1000 条记录。
- 学号必须事先登记且唯一；只有所选检索位置出现完整学号时才用于身份匹配。
- 邮箱发送依赖 QQ 邮箱 SMTP 设置和有效的客户端授权码。
